        The spreadsheet

        Same numbers, in a real workbook.

        The dashboard reads from the same example data as the Excel file. In the workbook, you type the budget once and log payments as they go out. The rollups are plain formulas, so nothing breaks when a row is added.

        Download the .xlsx

        Tamarack-budget-tracker-DEMO.xlsx · 5 tabs · opens in Excel, Google Sheets or Numbers. Example data.

        1. Budget vs Paid

          Original budget, approved change orders, paid, remaining and % spent per category. Over-budget rows turn red; a status column says Watch at 90%.

          =SUMIFS(Payments!F:F, Payments!C:C, A5)
        2. Payments

          Date, vendor, category, draw, invoice, amount, method, source, receipt. Dropdowns on category, method, source and receipt. No receipt turns the row red and flags it.

          =IF(I5<>"Yes", "MISSING RECEIPT", "")
        3. Change Orders

          Approved, pending or declined, signed or not. Only approved ones change the budget; approved but unsigned ones get flagged.

          =SUMIFS(…Amount, …Category, A5, …Status, "Approved")
        4. Read Me + Lists

          How to start with your own numbers, and the dropdown choices in one place. Categories come straight from the budget tab.

          CategoryList → 'Budget vs Paid'!A5:A19
